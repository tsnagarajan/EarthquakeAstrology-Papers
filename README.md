## ⚠️ NOTICE — August 2026: All Three Papers AND Forecast Calendar Withdrawn Pending Correction

This notice applies to all three documents in this repository — the **academic paper**, the **layman paper**, and the **forecast calendar**.

A rigorous reproducibility investigation, conducted after publication, found a data-leakage error in the original model: it had been trained on the full historical dataset, including the same events it was later validated against. After correcting this and testing honestly — across classical Vedic rules, rule combinations, an independent outer-planet hypothesis, and a region-specific re-validation of the paper's own claimed scope (Americas Pacific zone) — six independent tests all found no predictive signal above chance (MCC ≈ 0).

**The central finding of the academic and layman papers — validated predictive signal in the Americas Pacific zone — has been retracted by this follow-up investigation.** Please do not rely on any of these three documents, including the forecast calendar, for any planning or decision-making.

A full corrected writeup will follow.
